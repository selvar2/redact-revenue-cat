On the memory layer: I could not verify that a package named `notebook-lm-py` exists, so rather than
guess at an API I built the capability it describes — chunked, queryable, source-cited memory — using
Python stdlib only. No API key, no network, nothing that can rot. Chunking is by Markdown heading
rather than fixed windows because these notes follow a known template, so headings *are* the semantic
boundaries. Scoring is BM25 with the standard k1=1.5 / b=0.75; swapping in embeddings later is a
one-function change.

**Real code** — the heart of the retrieval scorer:

```python
def score(chunk, terms, doc_freq, total, avg_len):
    result = 0.0
    for term in terms:
        freq = chunk["tf"].get(term, 0)
        if not freq:
            continue
        n_q = doc_freq.get(term, 0)
        idf = max(0.0, math.log((total - n_q + 0.5) / (n_q + 0.5) + 1.0))
        norm = freq * (K1 + 1) / (freq + K1 * (1 - B + B * chunk["len"] / avg_len))
        result += idf * norm
    return result
```

IDF is floored at zero so a term present in every chunk contributes nothing rather than scoring
negative — without that, common words like "redaction" actively push relevant chunks *down*.

**Why XcodeGen instead of a committed `.pbxproj`:**

This is the decision that matters here. Parallel coding agents adding source files to a shared
`.pbxproj` produce constant merge conflicts — the file is a single flat blob with generated UUIDs,
and two agents touching it simultaneously corrupt it. With XcodeGen, agents write files to disk and
run `xcodegen generate`; project structure is derived from directory layout. Conflict-free by
construction, and `project.yml` is diffable in review.

Cost: `xcodegen generate` must be re-run after adding files. Encoded in `AGENTS.md`.

**Why a real screen instead of "Hello World":**

`CLAUDE.md` rule 10 forbids placeholders, and F01's acceptance criterion says *real first screen*.
It also proves the design-token port works before six agents build on top of it — cheaper to
discover a broken visual language now than after twenty views exist.
