**Why:**

Governance had to land *before* the first coding agent, not after. Agents read `CLAUDE.md` and
`AGENTS.md` to know their scope; writing those after parallel agents start means the first wave runs
unconstrained and collides.

Three rules carry most of the weight:

1. **No network** ([[DEC-004-no-network]]) — protects a truthful "No Data Collected" App Privacy
   answer, which is our biggest App Review advantage. Enforced by grep in `verify.sh`, not trust.
2. **Redaction must destroy data** — the product's entire claim. A black rectangle over live text is
   recoverable with `pdftotext`; a test must prove ours is not.
3. **Builders cannot mark their own work verified** — `feature_list.json` status is writable to
   `built` by builders, `verified` only by the independent verifier.

On the memory layer: I could not verify that a package named `notebook-lm-py` exists, so rather than
guess at an API I built the capability it describes — chunked, queryable, source-cited memory — using
Python stdlib only. No API key, no network, nothing that can rot. Chunking is by Markdown heading
rather than fixed windows because these notes follow a known template, so headings *are* the semantic
boundaries. Scoring is BM25 with the standard k1=1.5 / b=0.75; swapping in embeddings later is a
one-function change.

`docs/` is a valid Obsidian vault — frontmatter plus `[[wikilinks]]` — so the same files serve human
browsing with backlinks and machine retrieval.

**Real code** — the heart of the retrieval scorer:

```python
def score(chunk, terms, doc_freq, total, avg_len):
    result = 0.0
    for term in terms:
        freq = chunk["tf"].get(term, 0)
        if not freq:
            continue
        n_q = doc_freq.get(term, 0)
        idf = max(0.0, math.log((total - n_q + 0.5) / (n_q + 0.5) + 1.0))
        norm = freq * (K1 + 1) / (freq + K1 * (1 - B + B * chunk["len"] / avg_len))
        result += idf * norm
    return result
```

IDF is floored at zero so a term present in every chunk contributes nothing rather than scoring
negative — without that, common words like "redaction" actively push relevant chunks *down*.
